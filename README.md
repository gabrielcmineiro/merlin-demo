# Merlin · protótipo navegável

Protótipo de produto, em HTML estático. Abra `index.html`.

- 21 telas: dois inícios (direção e operação), inteligência, segmentos, campanhas, a montagem de uma campanha em cinco etapas, aprovação, resultado, registro e base.
- A situação das campanhas fica guardada no navegador. Para voltar ao começo, use "Recomeçar a demonstração" no menu da conta.
- Nada aqui envia mensagem nem grava dado em servidor.
- Campanhas, resultados, números de mídia e nomes de pessoas são ilustrativos.
- As fontes pagas não acompanham o repositório; sem elas instaladas, o navegador usa as alternativas.
